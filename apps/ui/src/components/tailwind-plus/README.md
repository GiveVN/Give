# Tailwind Plus Components

This folder contains components adapted from Tailwind Plus UI Blocks.

## Components

- Components here are converted to TypeScript
- Integrated with our existing design system
- Compatible with both shadcn/ui and Catalyst components

## Usage

Import components from this folder:

```tsx
import { ComponentName } from "@/components/tailwind-plus/ComponentName"
```

## Adding New Components

1. Copy the component code from Tailwind Plus
2. Create a new `.tsx` file in this folder
3. Convert to TypeScript if needed
4. Update imports to use our existing utilities
5. Export from the index file
